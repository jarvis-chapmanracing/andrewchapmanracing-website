# Truth rules

Use these rules every time.

## 1. Prefer official sources
Use the official company site, official press releases, official company social pages, and current LinkedIn profiles before third-party directories.

## 2. Separate facts from inference
Label these distinctly:
- verified fact
- likely match
- uncertain match

Never blur them together.

## 3. Avoid stale matches
Do not treat a person as current if the only evidence is old, mirrored, or undated.

## 4. Reject weak person matches
Reject the match when:
- the name is common and the company tie is unclear
- the source is only a people directory
- the role looks outdated
- the company domain does not match

## 5. Handle extraction failures carefully
If an official page renders poorly in fetch or hides key text in cards, scripts, or cookie-heavy layouts:
- use official-domain search results to locate the exact page
- treat search snippets from the official domain as supporting evidence, not sole proof
- try a second official page before downgrading to third-party sources

## 6. Preserve source links
Always keep source links with the result so the user can verify quickly.
